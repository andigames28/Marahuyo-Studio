MARAHUYO STUDIO WEBSITE

FILES
- index.html: Homepage
- about.html: About page
- works.html: Works / galleries page
- contact.html: Contacts page
- availability.html: Booking packages, FAQ and Google Calendar embed
- style.css: Shared responsive styling
- script.js: Slideshow, mobile menu and expandable galleries
- images/: replaceable image placeholders

NEEDS
1. Keep all HTML, CSS and JS files in the same folder.
2. Keep the images folder beside them.
3. Open index.html in a browser.

HOMEPAGE SLIDESHOW
The homepage rotates through four style images every 4 seconds. The category tabs can also be clicked to select a style manually.
Edit the styles object near the top of script.js if you want to change the slideshow timing, text or image filenames.

WORKS GALLERIES
Each collection starts with two large image panels. Hover on desktop or tap/click on mobile to reveal two more images.
